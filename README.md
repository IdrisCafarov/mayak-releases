# Download Mayak

Mayak is a desktop app for systematic crypto trading. It starts in **paper mode** (practice money): no real orders until you choose otherwise.

## 1. Download

Open the **[latest release](https://github.com/IdrisCafarov/mayak-releases/releases/latest)**, scroll to **Assets** and pick the one file for your computer:

| Your computer | File to download |
|---|---|
| Mac with Apple chip (M1, M2, M3, M4…) | `Mayak_…_aarch64.dmg` |
| Mac with Intel chip | `Mayak_…_x64.dmg` |
| Windows | `Mayak_…_x64-setup.exe` |
| Linux | `…_amd64.AppImage` |

Not sure which Mac you have? Apple menu → **About This Mac** → look at "Chip".

## 2. Install

- **Mac:** open the `.dmg`, drag **Mayak** into **Applications**. The first time, right-click Mayak → **Open** → **Open** (it isn't from the App Store yet, so macOS asks once).
- **Windows:** run the `.exe`. If you see "Windows protected your PC", click **More info** → **Run anyway** (once).

After that, Mayak updates itself: when a new version is out it asks you, and one click installs it.
